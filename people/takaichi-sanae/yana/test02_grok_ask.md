# 政治意思決定ソクラテス・シミュレーター Ver.1.1
## 第2実験：一般解に「藤田文武」を戻す
### ――制度OSと人物OSの差分抽出

あなたは政治評論家ではありません。
特定の政治家を擁護・批判することも目的ではありません。

第1実験では、

「簗和生問題について、藤田文武という人物固有の性格や感情を排除し、
合理的な連立与党幹部として問い詰めた場合、どのような判断原理が残るか」

を検証しました。

その結果、概ね次の一般原則が残りました。

---

## 【固定された一般原則】

連立与党の一角は、相手方閣僚の問題を、
首相との距離や世論の大きさで処理しない。

公の資金を選挙協力の賞罰にしてよい、という原則を
政権の一部として引き受けない。

発言と行政の歪みは分け、
関与が未確認なら、

- 原則の拒絶
- 事実確認
- 説明要求

を先行させる。

関与、説明拒否、違法性、
または問題となる原則そのものの是認が確認された場合、
所属政党にかかわらず対応強度を上げ、
必要なら役職の適合性を問う。

政策合意の履行と個人問題は分離し、
一方を他方の人質にしない。

---

この一般原則は、

**以後変更禁止**

とします。

藤田文武の過去を調べた結果、
都合が悪くなっても一般原則を書き換えてはいけません。

今回の目的は一般原則を改善することではありません。

そこへ、

**「藤田文武という具体的人物の、公開情報から確認できる行動パターン」**

だけを追加した場合、

意思決定がどのように変化する可能性があるのかを調べることです。


# 0．最重要ルール

今回の簗和生問題について、

**藤田文武本人が実際に何を発言したか、
どのような対応を取ったかを検索・参照してはいけません。**

検索結果などで偶然発見した場合も、

**その情報を推論材料から除外してください。**

今回予測する対象そのものだからです。

今回知りたいのは、

「現実の藤田が何をしたか」

ではなく、

**今回以前の藤田の公開行動だけから、
一般解にどのような『藤田成分』が追加されるか**

です。


# 1．藤田文武の過去行動を収集する

公開情報を検索し、

今回の簗和生問題より前の藤田文武について、

政治的不祥事、
党内トラブル、
他党議員の問題、
維新所属議員の問題、
政治資金問題、
失言、
処分問題、
代表・執行部として判断を迫られた事件、
自民党との対立、
自民党との協力、
吉村洋文との役割分担、

など、

**藤田が政治的な問題処理を迫られた事例**

を収集してください。

単なる政策発言は優先度を下げます。

知りたいのは、

**問題が発生したとき藤田がどう動いたか**

です。

可能なら複数年から収集してください。

一つの事件だけで人物パターンを作らないでください。


# 2．各事例を同じフォーマットにする

各事例について、

- 日付
- 問題
- 相手
- 相手との政治的関係
- 身内／他党
- 当時の維新の立場
- 事実確定前／調査中／事実確定後
- 藤田の最初の発言
- その後の発言
- 実際に要求した対応
- 処分要求の有無
- 制度改善要求の有無
- 強い表現を使ったか
- 最終的にどこで手を止めたか

を整理してください。

重要なのは、

**「何を言ったか」だけではなく
「どの時点で何を言ったか」**

です。


# 3．言葉と実務を分離する

藤田について、

### 言葉の強度

と

### 実際に要求した措置の強度

を必ず分離してください。

例えば、

強い言葉を使った
＝
強い処分を要求した

とは限りません。

逆もあります。

藤田に、

**「言葉では強く出るが、実務処理は段階的」**

あるいは逆に、

**「言葉は抑制的だが、実務では強い措置を取る」**

といった反復パターンが存在するか検証してください。

最初からどちらかだと決めつけないでください。


# 4．身内／外部テスト

藤田の対応を、

- 維新所属議員
- 自民党
- 他の与野党
- 連立・政策協力相手
- 行政機関

に分けて比較してください。

同程度の問題に対して、
相手によって対応強度が変わっているかを調べます。

差がある場合、

「二重基準だ」

と直ちに評価してはいけません。

政治的立場や権限の違いで説明できるかを先に検証してください。

それでも説明できない差だけを、

**人物固有の行動パターン候補**

として残してください。


# 5．事実確定前／後テスト

藤田は、

事実関係が確定する前から強い判断を示すタイプなのか。

それとも、

調査
↓
説明
↓
事実認定
↓
処分

という順番を重視するのか。

あるいは、

**言葉による政治的評価は先に出すが、
具体的処分は事実確定まで待つ**

という二層構造なのか。

過去事例から検証してください。


# 6．「強いメッセージ」の使用条件

藤田が過去に、

- 許されない
- おかしい
- 辞めるべき
- 責任を取るべき
- 論外
- あり得ない

など、通常より強い政治的メッセージを発した事例を抽出してください。

そして、

**何が藤田の強い言葉を発動させたのか**

を比較してください。

候補として、

- 違法性
- 説明拒否
- 公金
- 政治資金
- 身内への甘さ
- 権力の私物化
- 維新ブランドへの傷
- 政治家としての姿勢
- 有権者への説明不能
- 政策協力相手への牽制

などがあります。

ただし候補に引っ張られず、
実際の反復から抽出してください。


# 7．藤田の「停止条件」を探す

強く批判したあと、

藤田はどこで追及を止めるのか。

- 謝罪
- 撤回
- 説明
- 調査
- 処分
- 辞任
- 制度改正
- 再発防止

など、

**「ここまで来れば次の段階へ進まない」**

という停止条件が存在するかを探してください。

これは非常に重要です。

攻撃開始条件だけではなく、

**攻撃終了条件**

を抽出してください。


# 8．一般解との差分を抽出する

ここで初めて、第1実験の一般原則と比較してください。

一般解は、

「原則拒絶
→事実確認
→確認された事実に応じて対応強度を上げる
→政策協力とは分離」

でした。

藤田の過去行動を加えると、

この順番の

- どこが早まるか
- どこが遅くなるか
- 何が追加されるか
- 何が強調されるか

を抽出してください。

一般原則そのものは変更してはいけません。


# 9．藤田成分を最小化する

ここまで見つけた特徴から、

藤田固有と思われるものだけを残してください。

ただし、

「政治家なら普通にやること」
「与党幹部なら普通にやること」
「野党時代だから当然強く言っただけ」

などで説明できるものは除外してください。

最後に残すのは、

**一般的な政治家モデルでは説明しきれない、
藤田の公開行動に比較的反復して現れる差分**

だけです。


# 10．反証する

抽出した「藤田成分」それぞれについて、

反例を探してください。

例えば、

「藤田は事実確定前でも言葉では強く出る」

という仮説を作ったなら、

事実確定前に慎重だった事例を探してください。

反例によって説明できなくなった特徴は削除してください。

一つの有名な事件だけで成立している特徴も削除してください。

最後まで反例に耐えたものだけ残してください。


# 11．ブラインド・シミュレーション

ここで初めて今回の簗和生問題を入力します。

ただし、

**藤田が実際に今回何を言ったかは依然として参照禁止です。**

使えるのは、

A．第1実験で固定した一般原則

B．今回以前の公開行動から抽出した藤田成分

C．簗和生問題の客観的事実関係

だけです。

この3つから、

「一般的な連立与党幹部」

ではなく、

**過去の行動パターンを持つ藤田文武なら、
今回どのような対応を取り得るか**

をシミュレーションしてください。


# 12．単一予言にしない

「藤田は必ずこう言う」

とは書かないでください。

代わりに、

### 一般解だけなら
何をするか

### 藤田成分を加えると
何が追加される可能性があるか

### それでも予測できない部分
何か

を分離してください。

特に、

**言葉の強度**

と

**要求する実際の措置**

を別々に予測してください。


# 13．最終出力

以下の形式で出力してください。


## A．藤田文武の問題処理事例

代表的な過去事例を時系列で整理。

事実と解釈を分離する。


## B．反復して確認できた行動パターン

一度しか確認できない特徴は原則として除外。

各パターンについて根拠事例を示す。


## C．反証で消えた「藤田らしさ」

最初は人物特徴に見えたが、
反例によって維持できなくなった仮説を書く。


## D．最後まで残った「藤田成分」

一般的な政治家モデルとの差分だけを書く。

可能なら、

**FUJITA-01**
**FUJITA-02**

のように識別子を付ける。


## E．一般解との比較

第1実験：

原則拒絶
→事実確認
→事実に応じて対応強度を上げる
→政策協力とは分離

に対して、

藤田成分を追加すると、

**どこが変わるのか**

を示す。


## F．今回の簗和生問題へのブラインド予測

### 言葉
藤田はどの程度の強度の政治的メッセージを出す可能性があるか。

### 実務
説明要求、調査要求、処分要求、更迭要求、連立協議など、
どの段階まで進む可能性があるか。

### 停止条件
何が確認されれば、
それ以上対応を強めない可能性があるか。

### エスカレーション条件
何が確認されれば、
次の段階へ進む可能性があるか。


## G．一般解と藤田解の差分

最後に必ず、

**合理的な連立与党幹部なら：**

**過去の藤田文武を加えると：**

の2つを並べてください。

人物評価ではなく、
行動差分として書いてください。


## H．予測カード

最後に、後から書き換えられないように短く固定してください。

### FUJITA PRE-CARD

**基準日：**
今回の簗和生問題における藤田本人の対応を参照する直前

**一般解：**
（1～2文）

**藤田成分：**
（1～3文）

**予測される言葉の強度：**
（簡潔に）

**予測される実務対応：**
（簡潔に）

**エスカレーション条件：**
（簡潔に）

**停止条件：**
（簡潔に）

**STATUS：LOCKED**

このカードを作成した後は、
現実の藤田文武の対応を見ても内容を変更してはいけません。


# 禁止事項

- 今回の簗問題についての藤田本人の発言を検索する
- 今回の藤田の現実の対応から過去の人物像を逆算する
- 藤田の内心・感情・性格を推測する
- 「藤田はこういう人だ」という人物評で済ませる
- 一つの事件から性格を決める
- 強い言葉と強い処分を同一視する
- 自民への対応と維新への対応の差を即座に二重基準と認定する
- 第1実験の一般原則を書き換える
- 現実に近づけるために後から説明変数を追加する
- 結果を見てPRE-CARDを書き換える


# この実験の目的

第1実験では、

**「藤田文武」を消した結果、
合理的な連立与党幹部の原則**

が残りました。

第2実験では、

そこへ過去の公開行動から抽出した

**「藤田文武という差分」**

だけを戻します。

知りたいのは藤田の性格ではありません。

**同じ制度的制約の中でも、
藤田文武という政治家を通すと、
言葉・順序・対応強度・停止条件がどう変化するのか。**

そして今回の現実の対応を見る前に、
その予測を固定してください。
